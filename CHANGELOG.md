# Changelog

Notable changes to Linux Environment Manager are documented here. This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses semantic versioning.

## [Unreleased]

### Added

- GitHub Actions checks for frontend quality, Rust tests, and a complete Linux Tauri build.
- Conventional Commit-driven versioning and GitHub Releases with Linux AppImage, Debian, and RPM packages.

## [0.1.0] - 2026-11-03

### Added

- React and Tauri desktop app for user-scoped environment-variable management.
- Create, edit, delete-with-confirmation, and `.env` import/preview workflows.
- Atomic JSON persistence in the user's application configuration directory.
- Optional, reversible Bash and Zsh startup-file integration.
- Frontend and Rust tests, linting, type checking, and coverage checks.
